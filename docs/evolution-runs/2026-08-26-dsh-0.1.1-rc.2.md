- Web UI（最大变更面）：工具卡片体系重构、连接下行从轮询迁移到 WebSocket、设置页 Models/Provider UI 重做、新增首启 onboarding 弹窗、消息反馈、会话导出/搜索等。

- CLI：TUI 入口移除收口；`web` 新增默认打开系统浏览器与 `--no-open`。
- 其他：compaction 进度可见与策略改进、subagent 可安装 Codex/Claude provider、Linux bwrap /proc 逃逸修复、Windows ACL sandbox、credentials 文档格式升级（见适配 2）。

## 小妍侧适配（同一分支落地）

1. 启动参数追加 `--no-open`（`apps/desktop/src-tauri/src/dsh_process.rs`）：新版默认打开系统浏览器，会与 iframe 重复弹出；该 flag 要求 DSH ≥ 0.1.1，与锁定 manifest 配套。
2. `.credentials.yaml` 改写 versioned 布局（`apps/desktop/src-tauri/src/dsh_api_config.rs`）：写出 `version: 1` + `refs:`；合并时兼容旧 flat 顶层键并搬入 `refs`，保留 `records` 与其他 provider 条目；0600 权限与原子替换不变。旧写法会在 DSH 迁移后触发 `unknown top-level key` 硬失败，必须随升级同批落地。

## 遗留风险

- 若 `.credentials.yaml` 已含未知顶层键的混合文档，小妍保留未知键但不修复格式，需用户手工清理。
- 上游未来 `DOCUMENT_VERSION` 升到 2 时需同步 `DSH_CREDENTIALS_DOCUMENT_VERSION`。
