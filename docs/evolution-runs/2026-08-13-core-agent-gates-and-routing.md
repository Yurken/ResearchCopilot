# 2026-08-13 · 核心 Agent 门禁与显式检索边界

## 假设与边界

- 主假设：把 E01、E02、E06、E08 固化为可执行门禁后，可以发现并阻止“小妍在用户明确要求只用当前材料时仍启动检索步骤”的路由回归。
- OpenCode 参照点：vendored OpenCode 将任务 Agent 限制为只读搜索工具，把会话 busy/cancel 和事件类型作为显式契约；本轮借鉴其“按任务收窄能力、边界在运行前生效”的思路，不复制代码或扩大权限。
- 评测数据：`XCG-core-agent-gates` v1，4 个合成场景；不含真实聊天、论文、凭据或绝对用户路径。
- 迭代类型：评测基础设施与产品改进；没有更换或调用 Codex/小妍模型，不登记为模型升级。

## 决策

- 采纳：版本化核心门禁、三态证据和显式检索边界。
- 不宣称：E01/E02/E08 已达到真实用户或模型质量目标；当前只是代码证据基线。
- 杀停标准：目标切片杀停标准未触发；E06 提升、其他场景无已知退化。完整核心门禁仍未满足，不能用于正式模型采纳或发布放行。
