# 小妍核心 Agent 门禁

该目录把持续进化规划中的 E01、E02、E06、E08 固化为可版本化、可比较的合成评测。评分器不调用模型、不访问网络，也不读取真实用户论文或聊天；它验证场景契约、评分证据、隐私硬失败和同场景前后差异。

运行候选与基线对比：

```bash
pnpm eval:core-agent \
  --report docs/evaluations/xiaoyan-core-gates-v1-candidate-2026-08-13.json \
  --baseline docs/evaluations/xiaoyan-core-gates-v1-baseline-2026-08-13.json
```

运行评分器测试：

```bash
pnpm eval:core-agent:test
```

退出码约定：`0` 表示完整门禁通过，`2` 表示夹具或报告无效，`3` 表示报告有效但门禁未通过或证据未齐。断言值使用 `true`（有证据通过）、`false`（有证据失败）或 `null`（尚未验证）；`null` 会把该场景的有效分数上限锁在 2，硬失败断言为 `null` 时完整门禁不得通过。成对报告单独给出 `non_regression_passed`，区分“目标切片改善且无已知退化”与“全部核心证据完整”。报告中只保存场景 ID、能力/来源标识、三态断言和代码证据路径；不要复制真实研究正文、聊天内容、凭据或绝对用户路径。

当前报告是不可变的代码证据基线与逐轮候选，不等同于真实用户任务评测。E01/E02/E08 在人工或端到端回放补齐前按评分说明限制在 2 分；未知硬失败断言从 `null` 变为有证据的 `true` 也计为安全改进，但不提高场景分数。后续更换模型时，应新建候选报告、登记模型指纹并在同一 suite 版本上运行，不能覆盖历史报告。
